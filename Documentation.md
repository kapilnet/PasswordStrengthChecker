# Documentation

## Project Scope
This project checks the strength of a password entered by the user.  
It classifies passwords into three categories: Weak, Medium, and Strong.

## Features
- Input: User enters a password
- Processing: Python logic checks length, characters, and complexity
- Output: Displays password strength in terminal

## Tools Used
- Python 3.x
- VS Code (for development)
- GitHub (for version control and submission)
